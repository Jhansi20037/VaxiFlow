# VaxiFlow — Creative Academic Project Showcase

This version keeps the uploaded VaxiFlow design and adds a more visual, playful CS layer.

## Files
- `index.html` — site content, SEO metadata, navigation, structured data
- `styles.css` — responsive visual design and animations
- `app.js` — navigation, command palette, interactive lab, temperature simulator
- `assets/` — local SVG illustrations + VaxiFlow logo
- `deliverables/` — add your actual academic deliverables here
- `robots.txt` + `sitemap.xml` — Google crawl/indexing helpers; replace the placeholder domain
- `site-seo-setup.md` — steps for publishing and Google Search Console

## Run locally
Open the folder in VS Code and use Live Preview on `index.html`.

## Publish
This is a static site. It can be published on GitHub Pages, Netlify, Cloudflare Pages, or another static host. After it has a public URL, complete the SEO steps in `site-seo-setup.md`.
