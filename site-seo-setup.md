# VaxiFlow website — Google visibility setup

The files in this folder include basic SEO metadata, a sitemap, robots.txt and structured data. These **do not guarantee** a Google result by themselves.

## To make the website eligible to appear for “VaxiFlow”

1. Publish the website on a public URL.
2. Replace the placeholder canonical URL in `index.html` with the real public URL.
3. Replace the placeholder URL in `sitemap.xml` with the real public URL.
4. Keep `robots.txt` accessible at the site root.
5. Add the site to Google Search Console.
6. Submit the sitemap in Search Console.
7. Use URL Inspection to request indexing for the home page.
8. Search Google for the exact project name: **VaxiFlow**.

Google decides independently when and where a page appears. A unique project name helps, but no HTML file can force a search ranking or guarantee an instant result.

## Before publishing

- Replace the team/project email placeholders with the actual addresses.
- Replace the canonical/sitemap placeholders with the real domain.
- Confirm all project documents are the versions your team is comfortable showcasing publicly.
